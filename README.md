# MLOps Lab 3: Feature Selection

This lab explores **feature selection techniques** on the **Breast Cancer Wisconsin Dataset** to identify the most relevant features for predicting whether a tumor is **malignant** or **benign**. Feature selection is a critical step in building efficient and interpretable machine learning models, especially when working with datasets that contain many variables.

---

## Objective

The goal of this lab is to:
- Understand why feature selection is important
- Apply different feature selection techniques
- Compare model performance across selected feature subsets
- Explore how reducing feature dimensions affects model accuracy

---

## Dataset

The dataset used in this lab is **`breast_cancer_data.csv`**, which contains 569 tumor records with 30 numeric features computed from digital images of fine needle aspirates (FNA) of breast tissue.

The target variable:
| Value | Diagnosis |
|--------|-----------|
| 0      | Benign    |
| 1      | Malignant |
